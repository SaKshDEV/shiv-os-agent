# SHIV OS

SHIV is my personal AI companion project.

## Vision

Build an intelligent assistant that can help with desktop tasks, coding, browser automation, mobile interactions, and natural conversations.

## Core Principles

- Human approval for sensitive actions.
- Privacy and security by design.
- Verify actions instead of assuming success.
- Learn and build every feature step by step.
